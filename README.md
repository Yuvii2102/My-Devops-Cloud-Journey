## 🧭 Where It All Started

It has been almost a month since I started my journey into **DevOps and Cloud Engineering**.

I started learning, experimenting, and getting my hands dirty with different tools, technologies, commands, and cloud services.

But there was one thing I wasn't doing...

> ❌ **I wasn't documenting my journey.**

At the beginning, I didn't really understand how valuable documentation would be.

Now, I'm changing that.

From this point forward, this repository will document my journey — including the things I learn, the commands I practice, the problems I face, the mistakes I make, and the projects I build.

  📝 <b>Documentation Started:</b> August 14, 2026
